# 03. 麻雀牌画像の用意方法

## 結論

**[FluffyStuff/riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles)**（CC0 / パブリックドメイン）の SVG 素材を利用する。

## 選定理由

| 候補 | 評価 |
|---|---|
| **フリー素材 SVG（採用）** | 高品質・全牌種が揃っており手間ゼロ。SVG なのでどの画面サイズでも劣化しない |
| Unicode 麻雀牌文字（🀇🀙🀐 等） | 実装は最速だが OS・フォントで見た目が変わり品質が安定しない |
| コードで自作描画 | 自由度は高いが萬子・字牌の漢字の作り込みに時間がかかる |
| AI 画像生成 | 34 種 + α の見た目の一貫性を保つのが難しく、後処理も必要 |

## ライセンス

- FluffyStuff/riichi-mahjong-tiles のアセットは **CC0（パブリックドメイン）** として公開されており、商用含め自由に利用・改変できる（2026-07 時点でリポジトリの README に "All assets are in the public domain" と明記）
- 法的義務はないが、謝辞としてサイトのフッターや README に出典リンクを記載する

## 取得手順

1. リポジトリを ZIP でダウンロード（`https://github.com/FluffyStuff/riichi-mahjong-tiles` → Code → Download ZIP）
2. `Regular/` フォルダの SVG を使用する（`Black/` は黒背景バリアント。当面は Regular のみ採用）
3. 以下が揃っていることを確認する
   - 数牌 27 種（萬子・筒子・索子 各 1〜9）
   - 字牌 7 種（東・南・西・北・白・發・中）
   - 赤ドラ 3 種（赤五萬・赤五筒・赤五索）
   - 牌の裏面（Back）
4. 後述の命名規約にリネームして `src/assets/tiles/` に配置する
5. 出典とライセンスを記した `src/assets/tiles/LICENSE.md` を同梱する

## 牌の命名規約（MPSZ 表記）

ファイル名・コード内の牌 ID は、麻雀界で広く使われる **MPSZ 表記**に統一する。

| 種別 | ID | 例 |
|---|---|---|
| 萬子 | `m1`〜`m9` | `m1.svg` = 一萬 |
| 筒子 | `p1`〜`p9` | `p5.svg` = 五筒 |
| 索子 | `s1`〜`s9` | `s9.svg` = 九索 |
| 字牌 | `z1`〜`z7` | `z1`=東, `z2`=南, `z3`=西, `z4`=北, `z5`=白, `z6`=發, `z7`=中 |
| 赤ドラ | `m0` / `p0` / `s0` | `p0.svg` = 赤五筒 |
| 裏面 | `back` | `back.svg` |

- この ID は画像ファイル名だけでなく、`src/core/` の牌型（`TileId`）や「何切る」問題データの表記（例: `m123p456s789z11 + z1`）にもそのまま使う
- 手牌の文字列表記は `1m2m3m...` ではなく `m1m2m3...` のようにローマ字を前置する形で統一する（画像ファイル名と一致させるため）

## 牌表示コンポーネントの設計方針

- SVG は Vite の `import.meta.glob` などで一括インポートし、`<Tile id="m1" />` のような React コンポーネント経由でのみ表示する（生の `<img>` パスをゲーム側に書かせない）
- コンポーネントは以下を共通で担う
  - サイズ指定（高さ基準で幅は縦横比から自動算出）
  - 選択状態・無効状態などの見た目（枠線・半透明化）
  - タップ領域の確保（画像より広いヒットエリア、→ [01-platform.md](01-platform.md)）
  - アクセシビリティ（`aria-label="一萬"` のような日本語の牌名）
- 横向き牌（副露・リーチ宣言牌）が必要になったら CSS の `transform: rotate()` で対応し、画像は増やさない
