# 麻雀ミニゲーム集 ドキュメント

## プロジェクト概要

麻雀をテーマとしたミニゲームを多数作成し、1 つの Web サイトとして公開するプロジェクト。

### 目的

- 隙間時間（数十秒〜数分）でサッと遊べる麻雀ゲームを提供する
- 「何切る?」問題集や点数計算クイズなど、麻雀の上達にもつながるコンテンツを揃える
- ゲームを継続的に追加しやすい共通基盤（牌ロジック・牌表示 UI）を整備する

### スコープ

- 一人で完結するゲームのみ（一人打ち麻雀、クイズ、トレーニング系）
- 日本のリーチ麻雀のルールを前提とする
- PC・スマホのブラウザで動作すること

### 非スコープ（作らないもの）

- ネット対戦・マッチング機能
- アカウント登録・ログインなど、遊ぶまでに手間がかかる仕組み
- サーバーサイド処理（すべて静的サイトで完結させる）
