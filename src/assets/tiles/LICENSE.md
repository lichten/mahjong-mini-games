# 牌画像の出典

このフォルダの牌 SVG は [FluffyStuff/riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles) のアセット（Regular バリアント）を、本プロジェクトの命名規約（MPSZ 表記）にリネームして利用したものです。

- 元アセットのライセンス: **CC0 / パブリックドメイン**（"All assets are in the public domain"）
- リネーム対応: `Man1〜9 → m1〜m9` / `Pin → p` / `Sou → s` / `Ton,Nan,Shaa,Pei,Haku,Hatsu,Chun → z1〜z7` / `*5-Dora → m0,p0,s0`（赤五） / `Back → back` / `Front → front`（牌の白地。絵柄 SVG は透過背景のためこの上に重ねて表示する）
